
# SecondChance - User Story Template

## User Story

**Title:** User Registration

**As a** new user,
**I want** to create an account on SecondChance,
**so that** I can give away or receive second-hand household items.

## Acceptance Criteria

1. Users can register with a name, email, and password.
2. The system validates required fields.
3. Duplicate email addresses are rejected.
4. Passwords are stored securely.
5. Successful registration returns a confirmation message.
